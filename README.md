Este repositório reúne meus estudos em PHP, desenvolvidos durante o curso PHP Moderno, do Curso em Vídeo, ministrado pelo professor Gustavo Guanabara. Nele estão organizados os exercícios e desafios que realizei ao longo das aulas, com o objetivo de praticar a linguagem, entender melhor a lógica de programação e consolidar os conceitos apresentados no curso.

Os códigos foram escritos utilizando PHP, com apoio de HTML5 e CSS3 para a estrutura e aparência das páginas. Todo o desenvolvimento foi feito em ambiente local, utilizando o XAMPP como servidor e o Visual Studio Code como editor de código.

Ao longo dos exercícios e desafios, são trabalhados diversos conceitos fundamentais do PHP, como variáveis, constantes, operadores matemáticos e lógicos, estruturas condicionais e de repetição, funções, formulários com métodos GET e POST, uso de superglobais, manipulação de datas e números, divisão inteira com intdiv(), cálculo de resto de divisão, além de introdução ao consumo de APIs e integração entre PHP e HTML.

Todo o conteúdo didático utilizado como base pertence ao Curso em Vídeo. Este repositório não tem fins comerciais e foi criado exclusivamente para estudo e desenvolvimento pessoal.
